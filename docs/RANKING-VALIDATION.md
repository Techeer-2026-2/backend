# 음악 랭킹 검증 결과

2026-10-03, Windows / Java 21 / 실제 PostgreSQL 16.15에서 검증했다. Docker 엔진을 기동할 수 없어 테스트 전용 로컬 PostgreSQL과 `TEST_POSTGRES_EXTERNAL=true`를 사용했다. H2 대체 DB를 사용하지 않았다. 기본 CI는 기존 PostgreSQL Testcontainers 경로를 유지한다.

통합 테스트는 Flyway 신규 스키마 생성, 같은 이벤트의 동시 전송, 세션 시작 후 이동, 30초·100m·90% 경계, 시간 버킷 분리, 최소 인원 필터, 부모·도시·전체 fallback, 같은 시간 동시 배치 잠금, 재집계 중 DB 쓰기 오류 시 롤백, HTTP 입력 검증을 포함한다.

브라우저에서는 실제 실행 JAR와 별도의 데모 DB를 사용해 차트 렌더링, 곡 상세 열기·닫기, 새로고침을 확인했다. 브라우저 콘솔 오류는 없었다. 데모에는 곡 6개와 청취자 24명의 가상 데이터가 표시된다. 사용자 실제 위치 권한이나 실제 음원 재생은 검증에 사용하지 않았다.
