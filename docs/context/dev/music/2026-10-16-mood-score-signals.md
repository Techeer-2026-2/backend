## 왜
iTunes에는 분위기 정보가 없다. 어떤 방법이든 단독으로는 부정확했다. 정확도는 Spotify 수치(valence/energy)로 정한 기준 분위기 123곡과 비교해 쟀다 (임계값은 직접 정했으므로 참고용).

## 결과 (실험)
| 방법 | 결과 |
|---|---|
| 검색어 태그 (분위기별 검색어로 모은 곡에 그 분위기를 부여) | 62% |
| llama3.2:3b가 제목·가수로 판정 | 48% (한국곡 16곡은 14곡 일치) |
| 질문을 쪼개고 5회 다수결 | 18/29, 확신 채택 2/29 — 오히려 나쁨 |
| 미리듣기 오디오 분석 Essentia / CLAP | 13~14/28, 12~13/28 — 채택하지 않음 |
| 3신호 합의만 채택 | 75%, 단 29곡 중 20곡만 채택 |
- 위 3줄은 초기 라벨 28~29곡 기준이다. 이 라벨로 잰 모델의 79%는 라벨이 제목에 치우쳐 과대평가된 값이었다.

## 결정
- 점수 = 검색어 0.4 + 수치 데이터셋 0.4(데이터셋에 있는 곡만, 5개 분위기만) + 모델 0.2
- 쓸 수 없는 신호는 빼고 나머지로 가중평균
- 한계: 수치 데이터셋에 매칭되는 곡은 24%뿐(한국곡 19%). 가중치는 초안이며 정확도를 재측정하지 않았다.
- 데이터셋(maharshipandya/spotify-tracks-dataset)은 레포에 넣지 않았다.

## 대안
| 대안 | 기각 이유 |
|---|---|
| 모델 단독 | 48%, 한국곡 외에는 약함 |
| 오디오 분석 | 정확도가 낮고 CLAP 모델이 약 600MB |
| Spotify API | 2024-11-27부터 신규 앱에 audio features 차단 |
